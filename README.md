# Dice Game Project

## Description
This is a simple **Dice Game** for two players where each player takes turns to roll two dice. The player with the highest total after each turn wins. The game is implemented with a clean, interactive design and allows for an engaging, competitive experience. The dice roll results are displayed visually on the screen, and players can see their scores and the current winner.

Check out the project here: [Dice Game Project](https://github.com/Rahul-chhajed/dice_game)

## Features
- **Two-Player Mode:** Players take turns rolling two dice.
- **Visual Dice Roll:** Dice rolls are displayed with images representing the dice values.
- **Score Tracking:** The game keeps track of the score for both players.
- **Winner Announcement:** After each round, the winner is announced based on who rolled the higher sum of the dice.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Game Logic:** JavaScript (for handling the dice roll, score calculation, and winner determination)
